# Smart Home Companion App — Requirements (sample)

## 1. User Accounts

- **FR-1** Users must be able to sign up with email and password.
- **FR-2** Users must be able to reset a forgotten password via an emailed link that expires after 30 minutes.
- **FR-3** Users should be able to sign in with Google.

## 2. Device Management

- **FR-4** Users must be able to add a Wi-Fi device by scanning its QR code.
- **FR-5** The app must show each device's online/offline status, refreshed at least every 10 seconds.
- **FR-6** Users could group devices by room.

## 3. Automations

- **FR-7** Users must be able to create a schedule that turns a device on or off at a set time.
- **FR-8** The automation screen should be user-friendly.

## 4. Non-functional

- **NFR-1** The app should be fast.
- **NFR-2** All API traffic must use TLS 1.2 or higher.

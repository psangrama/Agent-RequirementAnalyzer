# PRD: Personal Task Board

Single `index.html` to-do app. No framework, no backend. Tasks saved in localStorage.

## Requirements
- Top nav with title, footer with dummy text
- Left nav: Today, Upcoming, Done (click to switch list)
- Add task (title + due date)
- Due today goes in Today, later dates in Upcoming
- Mark done moves task to Done
- Delete task
- Tasks persist after refresh
